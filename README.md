# GraphQL API with Node.js

## Description
A simple GraphQL API built with Node.js and Apollo Server. It allows you to query and mutate user data. Features include querying all users, querying by ID, and creating a new user.

## Technologies
- Node.js
- Apollo Server
- GraphQL
